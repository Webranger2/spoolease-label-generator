# 🖨️ SpoolEase Label Generator

[English](#english) | [Deutsch](#deutsch)

<a name="english"></a>
## 🇬🇧 English Documentation

A fast, lightweight, and offline-capable Progressive Web App (PWA) designed to generate sharp **50 × 30 mm** thermal printer labels for 3D printing filament spools based on **SpoolEase** inventory data and NFC URLs.

### ✨ Features

* **📲 NFC Link Parsing:** Import spool data instantly by pasting your SpoolEase NFC URL.
* **📱 Mobile First & Responsive:** Optimized UI for smartphones, tablets, and desktop browsers.
* **📸 Native Mobile Save:** Direct support via the Web Share API to save label PNGs directly into your iOS Photos / Android Gallery.
* **🖨️ High-DPI Output:** Renders at crisp 1200 × 720 px to ensure readable QR codes and sharp text on thermal label printers (Nelko, Niimbot, Labelife, Phomemo, etc.).
* **🌐 Offline PWA Support:** Installable as a standalone app on iOS, Android, and Desktop. Works 100% offline.
* **🌍 Bilingual:** Built-in German (DE) and English (EN) language toggles.
* **🏁 Monochrom / Mono Mode:** Dedicated toggle for clean black-and-white printing.

### 🚀 How to Use

1. **Set Inventory Base URL:** Enter your local SpoolEase instance address (e.g., `http://spoolease.local/app/inventory`).
2. **Import NFC URL:** Paste the URL generated during SpoolEase NFC tag encoding and click **Import URL**.
3. **Verify Data:** Adjust material, color, temperatures, or spool IDs if needed.
4. **Export / Share:**
   * **Mobile:** Tap **"📸 In Fotos / Galerie speichern"** to save or send the image directly to your printer companion app.
   * **Desktop:** Tap **"PNG Herunterladen"** or open in a new tab to print via standard OS print dialogs (`50x30mm`, 100% scale).

### 📱 Installation (PWA)

* **iOS (Safari):** Tap the **Share icon** → **Add to Home Screen**.
* **Android (Chrome):** Tap the **Menu (three dots)** → **Add to Home Screen** / **Install App**.
* **Desktop (Chrome/Edge):** Click the **Install Icon** in the address bar or go to **Menu → Save and share → Install page as app**.

<a name="deutsch"></a>
## 🇩🇪 Deutsche Dokumentation

Eine schnelle, schlanke und offline-fähige Progressive Web App (PWA) zur Erstellung gestochen scharfer **50 × 30 mm** Etiketten für Thermodrucker auf Basis von **SpoolEase** Filament- und NFC-Daten.

### ✨ Funktionen

* **📲 NFC-Link-Import:** Automatische Übernahme aller Spulendaten durch Einfügen der SpoolEase NFC-URL.
* **📱 Mobile-First Design:** Vollständig optimierte Benutzeroberfläche für Smartphones, Tablets und Desktops.
* **📸 Direktes Speichern auf Mobilgeräten:** Nutzt die native Web Share API zum direkten Speichern in iOS Fotos oder der Android Galerie.
* **🖨️ High-DPI Druckausgabe:** Rendert in knackigen 1200 × 720 px für perfekt lesbare QR-Codes und Text auf Thermodruckern (Nelko, Niimbot, Labelife, Phomemo usw.).
* **🌐 Offline PWA-Unterstützung:** Als eigenständige App auf iOS, Android und PC/Mac installierbar. Läuft 100% offline.
* **🌍 Zweisprachig:** Integrierter Schalter für Deutsch (DE) und Englisch (EN).
* **🏁 Monochrom-Modus:** Spezieller Schalter für sauberen Schwarz-Weiß-Druck ohne Graustufen.

### 🚀 Anleitung

1. **Inventory-Basis-URL eintragen:** Gib die Adresse deiner lokalen SpoolEase-Instanz ein (z. B. `http://spoolease.local/app/inventory`).
2. **NFC-URL importieren:** Füge den beim NFC-Tag-Codieren erzeugten Link ein und klicke auf **URL Importieren**.
3. **Daten prüfen:** Passe Material, Farbe, Temperaturen oder Spulen-ID bei Bedarf an.
4. **Exportieren & Drucken:**
   * **Mobil:** Tippe auf **"📸 In Fotos / Galerie speichern"**, um das Bild direkt in der Druckersoftware (z. B. Nelko App) zu öffnen.
   * **Desktop:** Klicke auf **"PNG Herunterladen"** oder öffne das Label in einem neuen Tab zum Drucken über das Betriebssystem (`50x30mm`, 100 % Skalierung).

### 📱 App-Installation (PWA)

* **iOS (Safari):** Tippe auf das **Teilen-Symbol** → **Zum Home-Bildschirm**.
* **Android (Chrome):** Tippe auf die **Drei Punkte** → **Zum Startbildschirm hinzufügen** / **App installieren**.
* **Desktop (Chrome/Edge):** Klicke auf das **Installieren-Symbol** in der Adressleiste oder öffne das Menü (Drei Punkte) → **Speichern und teilen** → **Seite als App installieren**.
